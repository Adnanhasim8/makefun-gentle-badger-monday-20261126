# Monday Morning Punchlines

One funny Monday-morning punchline, written by a small Python program for the
make.fun competition `u-gentle-badger-68-monday-morning-punchlines-709645dc`.

The entry: **"My blanket filed a restraining order against my Monday alarm."**

## How to run

```sh
python3 main.py
```

This writes a single line (61 characters) to `/output/entry.txt`. Python 3.13
standard library only, no network access at run time.
